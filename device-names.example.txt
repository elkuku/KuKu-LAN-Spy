# Custom device names for render-html.php.
# Copy to device-names.txt (which git ignores) and edit.
#
# One device per line: a MAC or IP address, then the name.
# MACs are preferred since IPs can change; use an IP for devices with a
# randomized MAC. Case does not matter and '-' works in place of ':'.
#
# The icon is guessed from the scan and from words in the name (cam, pixel,
# tv, luz, ...). To pick it yourself, put a type in brackets before the name:
# router wifi computer laptop server phone tablet tv camera speaker printer
# bulb plug unknown

aa:bb:cc:dd:ee:ff  Living room TV
192.168.1.50       Printer (office)
1c:90:ff:4c:1e:a2  [plug] Garden pump
